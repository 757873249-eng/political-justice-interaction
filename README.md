# 政治正义的实践逻辑：课堂互动

这是一个可直接部署到 GitHub Pages 的单次课堂互动页面。

## 互动设计

学生扫码进入后，在有限公共资源情境下作出一个选择。页面随后揭示选择背后的正义标准，并提出一个需要现场辩护的追问。最后用三个公共决策问题收束互动：谁被纳入、谁被暂时放在后面、谁可以推动修正。

页面不收集、不保存、不统计任何个人选择，所有状态只存在于当前浏览器页面。

## 发布到 GitHub Pages

将 `political-justice-interaction` 目录上传到 GitHub 仓库，在仓库设置中开启 Pages，并选择该目录所在分支的根目录作为发布源。发布后，将 Pages 地址生成二维码放入 PPT。
